# 강의 자료

철근콘크리트 수업에서 말로 설명하기 까다로운 대목을 골라, 값을 바꿔 가며
확인할 수 있게 만들었다.

## 대화형 탐색기

노트북을 실행하지 않고 **브라우저에서 바로 값을 바꿔 보려면**
[대화형 탐색기](_static/explorer.html)를 연다. 슬라이더를 움직이면 그래프가
따라 바뀐다.

| 탭 | 바꿀 수 있는 값 | 보이는 것 |
|---|---|---|
| 기둥 | $f_{ck}$, $f_y$, 띠철근/나선철근, 작용 축력 | $\phi(\varepsilon_t)$ 곡선, 단면 분류로 색을 입힌 P-M 상관도 |
| 보 | $f_{ck}$, $f_y$, 인장철근 개수 | 철근 개수·강도에 따른 $\phi M_n$, $\varepsilon_t$, $M_{cr}$, 손계산 대조 |

브라우저에서는 파이썬을 돌릴 수 없으므로, 매개변수 격자 위의 해석 결과를 미리
계산해 페이지에 담아 두었다. 격자 밖의 값이 필요하면 노트북에서 직접 계산한다.

## 각 편의 구성

- **이 시간에 답할 질문** — 도입에서 던지고 마지막에 회수한다
- **아래 코드가 하는 일** — 모든 코드 셀 앞에 무엇을 계산하는지 적었다
- **설계의 의도** — 기준이 왜 그렇게 정했는지를 절마다 다룬다
- **직접 바꿔 보기** — 학생이 값을 바꿔 재실행하는 셀. 주석에 `← 바꿔 보라` 로 표시
- **생각해 볼 문제** — 계산만으로는 답이 안 나오는 문항. 과제로 쓸 수 있다

내려받아 실행하려면 [설치](installation.md) 를 따른 뒤:

```shell
jupyter lab docs/lectures/
```

## 그림의 한글

강의용 노트북은 축 라벨까지 한글로 쓴다. 첫 셀이 설치된 한글 글꼴을 찾아
matplotlib 에 등록하며, 찾지 못하면 경고만 내고 넘어간다. 글자가 깨지면
나눔고딕이나 Noto Sans KR 을 설치한다.

```shell
pip install koreanize-matplotlib   # 글꼴 파일만 받아 쓰는 가장 쉬운 방법
```

저장소의 노트북에는 **실행 결과가 이미 저장되어 있으므로**, 문서 사이트에서
읽기만 할 때는 글꼴이 없어도 그림이 정상으로 보인다.

## 다시 만들기

`.ipynb` 를 직접 고치지 말고 생성 스크립트를 고친 뒤 다시 만든다.

```shell
python scripts/build_lectures.py --run   # 노트북
python scripts/explorer_data.py          # 탐색기의 값 (몇 분 걸린다)
python scripts/build_explorer.py         # 탐색기 페이지 조립
```
