# 강의 자료

[예제](examples.md)가 "이 함수를 이렇게 쓴다"를 보인다면, 강의 자료는 **"이
현상이 왜 이런가"**를 그림으로 설명한다. 학부 철근콘크리트 수업에서 말로
설명하기 까다로운 대목을 골라, 값을 바꿔 가며 확인할 수 있게 만들었다.

| 편 | 다루는 것 | 답하는 질문 |
|---|---|---|
| [L2 · 강도감소계수 $\phi$](lectures/L2_강도감소계수.ipynb) | KDS 14 20 10 4.3.3(2) | $\phi$ 는 무엇의 함수인가? 설계 상관도는 왜 공칭 상관도와 평행하지 않은가? |

## 쓰는 법

노트북을 그대로 화면에 띄워도 되고, 셀을 실행하며 값을 바꿔 보여 줘도 된다.
각 편은 다음 구성을 따른다.

- **이 시간에 답할 질문** — 도입에서 던지고 마지막에 회수한다
- **볼 것** — 그림 앞에 무엇을 눈여겨볼지 한 줄로 적었다
- **직접 바꿔 보기** — 학생이 값을 바꿔 재실행하는 셀. 주석에 `← 바꿔 보라` 로 표시
- **생각해 볼 문제** — 계산만으로는 답이 안 나오는 문항. 과제로 쓸 수 있다

내려받아 실행하려면 [설치](installation.md) 를 따른 뒤:

```shell
jupyter lab docs/lectures/
```

## 그림의 한글

강의용 노트북은 축 라벨까지 한글로 쓴다. 첫 셀이 설치된 한글 글꼴을 찾아
matplotlib 에 등록하며, 찾지 못하면 경고만 내고 넘어간다. 글자가 깨지면
나눔고딕이나 Noto Sans KR 을 설치한다.

```shell
pip install koreanize-matplotlib   # 글꼴 파일만 받아 쓰는 가장 쉬운 방법
```

저장소의 노트북에는 **실행 결과가 이미 저장되어 있으므로**, 문서 사이트에서
읽기만 할 때는 글꼴이 없어도 그림이 정상으로 보인다.
