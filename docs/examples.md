## 02 — 단면 제원

총단면 제원과, 콘크리트 탄성계수를 기준으로 한 환산단면 제원을 출력한다.
`GrossProperties` 의 단면2차모멘트는 $EI$ 이므로, 순수한 $I$ 는 환산단면 제원에서
얻는다.

## 03 — 균열단면

```
파괴계수           fr   = 3.274 MPa
총단면 2차모멘트   Ig   = 7,912,837,641 mm^4
균열모멘트         Mcr  = 88.42 kN.m
중립축 깊이        d_nc = 146.93 mm
균열단면 2차모멘트 Icr  = 2,226,509,867 mm^4
Icr / Ig                = 0.281
```

Branson 식에 의한 유효단면2차모멘트도 함께 계산한다.

$$I_e = \left(\frac{M_{cr}}{M_a}\right)^3 I_g +
\left[1 - \left(\frac{M_{cr}}{M_a}\right)^3\right] I_{cr} \le I_g$$

| $M_a/M_{cr}$ | 1.0 | 1.2 | 1.5 | 2.0 | 3.0 |
|---|---:|---:|---:|---:|---:|
| $I_e/I_g$ | 1.000 | 0.697 | 0.494 | 0.371 | 0.308 |

## 06 — 2축 휨

$N_d = 1200$ kN 에서 16방향의 설계 휨강도를 계산한다. 정사각형 대칭 단면이므로
$\phi M_{nx} = \phi M_{ny} = 386.2$ kN·m 이며, 45° 방향에서 209.1 kN·m 로 가장 작다.
강도감소계수도 방향에 따라 0.688 ~ 0.828 로 달라진다 — 같은 축력이라도 중립축
방향에 따라 순인장변형률이 달라지기 때문이다.

## 07 — 모멘트-곡률

```
균열모멘트          Mcr          = 88.42 kN.m
최대 모멘트 (해석)  Mmax         = 313.15 kN.m
극한 휨강도         Mn           = 313.29 kN.m
최대 곡률           kappa_max    = 5.313e-05 1/mm
```

사용 응력-변형률 관계로 계산한 최대 모멘트(313.15 kN·m)가 등가직사각형 응력블록으로
계산한 극한 휨강도(313.29 kN·m)와 0.05 % 이내로 일치한다.

## 08 — 응력 해석

사용 모멘트 $M = 1.5 M_{cr} = 132.6$ kN·m 에서의 응력이다.

```
       비균열 | 콘크리트    -4.91 ~    5.15 MPa | 철근    -29.12 ~    31.26 MPa
        균열 | 콘크리트     0.00 ~    8.75 MPa | 철근   -174.93 ~    39.68 MPa
        사용 | 콘크리트     0.00 ~    8.75 MPa | 철근   -174.96 ~    39.69 MPa
        극한 | 콘크리트     0.00 ~   22.95 MPa | 철근   -400.00 ~   160.29 MPa
```

극한 상태의 콘크리트 압축응력 22.95 MPa 는 $\eta(0.85 f_{ck}) = 1.0 \times 0.85
\times 27$ 과 일치하고, 철근의 인장응력 −400 MPa 는 SD400 의 항복강도와 일치한다.

## 17 — 교량 바닥판 설계 (KDS 24)

PSC 거더교(총폭 12.6 m, 거더 5본 @ 2.5 m, 캔틸레버 1.3 m)의 바닥판을 내측부와

주는 근사식으로 끝난다.

```

                                        활하중의 몫 87 %
④ 극한 I  1.25 DC + 1.50 DW + 1.80 (LL+IM) = 62.08 kN.m/m
⑤ 내측부  필요 As 1052, 배치 D16@150 = 1340 mm2/m
          M_Rd = 77.36 kN.m/m,  M_Rd/M_Ed = 1.25
⑥ 캔틸레버  M_Ed = 129.95 kN.m/m  (내측부의 2.1 배)
          헌치 280 mm, 상부 D19@125 → M_Rd = 152.90,  비 1.18
⑦ 배력철근  120/√L = 75.9 % → 상한 67 % → D13@148 이하
⑧ 사용성   내측부 f_s 166.2 MPa,  캔틸레버 175.3 MPa   모두 만족
          처짐 한계 L/800 = 3.1 mm,  피로 검증 불필요,  전단 검토 생략 가능
⑨ KDS 14  같은 M_Ed 에 필요 철근량 2.3 ~ 3.5 % 더 요구
```

**캔틸레버가 왜 지배하는가.** 방호벽 자중 때문이라고 생각하기 쉽지만
설계휨모멘트 증가분 67.9 kN·m/m 의 **82 % 가 활하중**이다. 고정하중의 몫은
13 % 에서 19 % 로 늘 뿐이다. 연속판의 0.8배 혜택이 없고, 윤하중이 폭 1.94 m 에만
퍼진 채 1.0 m 지렛대 팔로 걸리기 때문이다.

방호벽에 작용하는 차량 충돌하중(KDS 24 90 11, 극단상황한계상태)은 이 예제의
범위 밖이다. 실제 설계에서는 캔틸레버 상부철근이 충돌하중으로 결정되는 경우가
많다.

## 18 — PSC I형 거더 설계 (KDS 24)

지간 30 m 단순 지지 PSC 거더교의 주형을 설계한다. 예제 17 의 바닥판이 이 거더
위에 얹히므로, **합성 전후로 저항 단면이 달라지는 것**이 핵심이다.

```
① 거더 PSC-I 2.0m  A 0.881 m2, y_b 962 mm  ->  합성 A 1.415, Z_b 1.47 배
② 하중  거더자중 2428 + 바닥판 1654 (거더 단독이 받는 몫 59.4 %)
         2차고정 338 + 활하중·충격 2456 (합성 단면)
         극한 I  M_Ed = 1.25 x 4419 + 1.80 x 2456 = 9945 kN.m
③ 도입응력  f_o,max = min(0.8 x 1860, 0.9 x 1600) = 1440 MPa
④ 손실  마찰 7.9 + 정착 2.8 + 탄성 2.1 + 장기 8.1 = 20.9 %
         P_i 4351 kN  ->  P_e 3948 kN
⑤ 사용  하연 -2.37 MPa <= f_ctk 2.62  ->  비균열
⑥ 극한  M_Rd 10091 >= M_Ed 9945 kN.m  (여유 1.01 배)
⑦ 텐던  중앙 편심 762 mm, 핵거리 457 mm  ->  드레이프 필요
⑧ 수량  20 m 16가닥(극한 지배) ~ 50 m 61가닥(사용 지배)
⑨ KDS 14  M_Rd 가 phi M_n 보다 +4.8 %
```

**강도가 남는데 왜 단면이 커지는가.** 35 m 를 넘으면 극한 휨강도가 1.09 ~ 1.14
배로 남는데도 강연선을 더 넣어야 한다. **사용한계상태의 균열 검토**가 수량을
정하기 때문이다. 극한이 요구하는 것은 긴장재의 인장력이라 가닥 수에 거의
비례하지만, 사용한계상태가 요구하는 하연 압축은 $M/Z_b$ 에 밀린다. 지간이 길어질
때 $M$ 은 $L^2$ 로 느는데 $Z_b$ 는 형고가 허용하는 만큼만 큰다.

**텐던을 왜 휘는가.** 지간 중앙에서는 편심이 클수록 좋고, 상한은 응력이 아니라
하부플랜지의 기하다. 그런데 단부에서는 자중 모멘트가 0 이라 프리스트레스가 만드는
상연 인장을 상쇄할 것이 없고, 상한이 핵거리 $Z_t/A = 457$ mm 로 내려온다. 중앙의
762 mm 를 단부까지 끌고 가면 상연 인장이 3.30 MPa 로 긴장 시 $f_{ctk}$ 2.20 MPa
를 넘어 갈라진다. 드레이프는 시공 편의가 아니라 응력이 요구하는 형상이다.

:::{warning}
이 예제가 쓰는 `EXAMPLE_SECTIONS` 는 **예시 단면이며 어떤 표준도도 아니다.**
형상은 일반적인 PSC I형 거더를 본떴을 뿐이므로, 실제 설계에는 해당 표준도나
제작사 제원을 써야 한다.
:::

:::{note}
**식 $(1.5\text{-}9)$ 는 읽기가 갈린다.** 원문은 두 계수를 모두 $f_{py}$ 에
곱해 한계가 1,200 MPa 이고, EN 1992-1-1 5.10.3(2) 및 바로 앞 식
$(1.5\text{-}7)$ 의 방식으로 읽으면 1,360 MPa 다. 원문대로면 식
$(1.5\text{-}7)$ 이 허용하는 1,440 MPa 에서 즉시손실이 16.7 % 를 넘어야 하는데
통상적인 포스트텐션 거더는 12 ~ 15 % 이므로, 식 $(1.5\text{-}9)$ 가 식
$(1.5\text{-}7)$ 의 상한을 사실상 1,378 MPa 로 끌어내린다. `design_girder` 는
기본값으로 EN 해석을 쓰며, `transfer_reading="원문"` 으로 원문 해석도 검토할 수
있다. **이는 해석상의 선택이므로 실무에서는 발주자·감리와 맞추어야 한다.**
:::

## 19 — PSC I형 거더 전단설계 (KDS 24)

예제 18 에서 휨으로 설계한 **그 거더**의 전단을 검토한다. 휨에서 프리스트레스는
하중을 상쇄하는 역할이었지만, **전단에서는 콘크리트 강도식에 직접 들어간다.**

```
① 거더        P_e 3948 kN (손실 20.9 %),  b_w 290 mm,  d_p 2090 mm
② V_Ed        지점 1339 -> 중앙 196 kN   (휨과 반대로 지점이 최대)
③ f_n         P_e/A = 2.790 MPa  (상한 0.2 phi_c f_ck = 5.20)
④ V_cd        f_n 무시 412.5  ->  반영 666.1 kN   (+62 %)
⑤ 구간        x = 8.7 m 부터 계산상 스터럽 불필요 (지간의 29 %)
⑥ cot θ       2.29 를 넘으면 스터럽보다 스트럿이 먼저 깨진다
⑦ 스터럽      D13 2가닥, cot θ 2.0 -> 지점부 @510, 중앙부 @691 이하
⑧ 최소철근    계산상 필요 없어도 넣는다 - 전단 파괴는 예고가 없다
⑨ KDS 14      f_n 을 빼면 KDS 24 가 보수적, 넣으면 뒤집힌다
```

**프리스트레스가 전단강도가 되는 이유.** 전단균열은 복부의 주인장응력이
콘크리트 인장강도를 넘을 때 생긴다. 축압축이 걸려 있으면 모어원이 통째로 압축
쪽으로 밀려 주인장응력이 줄어든다. 그래서 식 $(4.1\text{-}7)$ 에 $0.15 f_n$ 이
직접 더해진다. 다만 $f_n$ 은 **유효** 프리스트레스로 계산해야 한다 — 긴장력을
쓰면 손실 21 % 만큼 전단강도를 과대평가한다.

**$\cot\theta$ 는 공짜가 아니다.** 스트럿을 눕히면 한 균열을 가로지르는
스터럽이 많아져 $V_{sd}$ 가 비례해 커지지만, 같은 $\cot\theta$ 가
$V_{d,\max}$ 의 분모에 들어가 스트럿 압축을 키운다. 이 거더에서는 2.29 에서
두 곡선이 만나고, 그 위로는 $\cot\theta$ 를 키워도 강도가 늘지 않는다.
기준이 $1 \le \cot\theta \le 2.5$ 로 묶어 둔 까닭이다.
