## 바닥판은 왜 따로 다루는가

거더는 **선부재**다. 한 방향으로 길고 단면력이 한 축을 따라 흐르므로, KL-510
트럭을 굴려 영향선의 최대값을 찾는 것이 자연스럽다.

바닥판은 **판**이다. 윤하중 하나가 실리면 힘은 사방으로 퍼지고, 거더 사이에서
아치처럼 버티기도 한다. 정직하게 풀려면 판 해석을 해야 하는데 다리 하나에
바닥판 단면은 수백 개다.

그래서 기준은 **실물 실험으로 보정한 근사식**을 준다.

$$
M_t = \frac{(L + 0.6)\,P}{9.6} \qquad [\text{kN} \cdot \text{m/m}]
$$

여기서 $L$ 은 거더 간격, $P$ 는 윤하중 96 kN(KL-510 의 192 kN 축의 절반)이다.
**트럭의 위치도, 축간거리도, 다차로 재하계수도 나오지 않는다.** 이 식이 이미
윤하중의 횡방향 분포와 판의 2방향 거동을 삼키고 있기 때문이다.

연속판은 여기에 0.8 을 곱한다.

```python
from concreteproperties_kds.kds24 import live_load_moment

live_load_moment(span=2.5, continuous=True)     # 연속판
```

## 하중과 조합

| 항목 | 조문 | 내용 |
|---|---|---|
| 바닥판 지간 | 24 10 11 4.6.2.3 | 거더 간격에서 복부 두께를 뺀 값 등 |
| 활하중 휨모멘트 | 식 (4.6-1) | 위 식 |
| 등가 분포폭 | 식 (4.6-2) | $E = 1.2 + 0.06L \le 2.1$ m |
| 캔틸레버 | 식 (4.6-4) | $E = 0.8X + 1.14$ |
| 고정하중 | 표 4.6-2 | $wl^2/8$, $\pm wl^2/10$, $-wl^2/2$ |
| 충격 | 24 12 21 표 4.4-1 | 25 % |
| 하중조합 | 24 12 11 표 4.1-1 | 극한Ⅰ |

바닥판은 **활하중이 압도적으로 지배한다.** 거더 간격 2.5 m, 두께 240 mm 의
전형적인 조건에서 설계휨모멘트의 **87 %** 가 활하중이다.

## 강도가 먼저 걸리는가, 균열이 먼저 걸리는가

바닥판은 얇고 활하중이 지배하므로 **균열 제어가 강도만큼 자주 설계를
정한다.** 표 4.2-5 는 철근 응력에 따라 최대 간격을 제한하는데, 거더 간격
2.5 m · 두께 240 mm 조건에서 강도가 요구하는 간격은 216 mm, 균열이 허용하는
간격은 225 mm 로 4 % 차이다.

**철근을 굵게 하면 순서가 뒤집힌다.** D19 부터는 균열(간격) 조건이 먼저
걸린다. 굵은 철근을 넓게 벌리면 같은 철근량이라도 균열폭이 커지기 때문이다.

## 무엇을 올려야 효과가 있는가

기준 조건에서 각 변수를 10 % 올렸을 때 $M_{Rd}$ 의 변화는 이렇다.

| 변수 | $M_{Rd}$ 변화 |
|---|---|
| 바닥판 두께 | **+11.1 %** |
| 철근량 | +7.8 % |
| 거더 간격(줄일 때) | +5.7 % |
| 포장 두께 | +0.2 % |

**두께가 가장 잘 듣는다.** 두께를 키우면 자중도 늘지만, 바닥판 하중의 87 % 가
활하중이라 자중 증가가 이득의 4 % 밖에 갉아먹지 않는다. 거더의 경우와 다른
점이다.
