## 도입응력의 상한

**식 (1.5-7)** 은 긴장 시 최대 응력을 준다.

$$
f_{o,\max} = \min(0.80 f_{pu},\; 0.90 f_{py})
$$

두 조건이 하는 일이 다르다. $0.80 f_{pu}$ 는 **끊어지지 않게**, $0.90 f_{py}$ 는
**항복하지 않게** 하는 조건이다. 두 조건이 같아지는 항복비는

$$
\frac{f_{py}}{f_{pu}} = \frac{0.80}{0.90} = 0.889
$$

인데, 보통 강연선의 항복비는 0.85 ~ 0.86 이므로 **거의 항상 $0.90 f_{py}$ 가
지배한다.**

```python
from concreteproperties_kds.kds24 import max_jacking_stress

max_jacking_stress(fpu=1860, fpy=1600)   # 1440.0 = 0.9 x 1600
```

## 식 (1.5-9) — 읽기가 갈리는 조문

:::{warning}
**이 조문은 두 가지로 읽힌다. 설계 전에 정해 두어야 한다.**
:::

KDS 24 14 21 1.5.7.3(1) 원문은 도입 직후 긴장재 응력 $f_{pmo}$ 를
"$0.75 f_{py}$ 또는 $0.85 f_{py}$ 중 작은 값"으로 적는다. 두 계수를 **모두**
$f_{py}$ 에 곱하므로 작은 쪽인 $0.75 f_{py}$ 가 언제나 이긴다.

그런데 바로 앞 식 (1.5-7) 은 인장강도와 항복강도를 짝지어 쓰고, 대응하는
EN 1992-1-1 5.10.3(2) 도 $\min(0.75 f_{pk},\ 0.85 f_{p0.1k})$ 로 둘을 짝짓는다.

$f_{pu}$ 1,860 / $f_{py}$ 1,600 강연선이면 차이가 이렇다.

| 읽는 방식 | 계산 | 한계 |
|---|---|---|
| 원문 그대로 | $\min(0.75 \times 1600,\ 0.85 \times 1600)$ | **1,200 MPa** |
| EN 방식 | $\min(0.75 \times 1860,\ 0.85 \times 1600)$ | **1,360 MPa** |

**원문대로 읽으면 식 (1.5-9) 가 식 (1.5-7) 을 무력화한다.** 식 (1.5-7) 이
허용하는 1,440 MPa 에서 1,200 MPa 로 내려오려면 즉시손실이 16.7 % 를 넘어야
하는데, 통상적인 포스트텐션 거더의 즉시손실은 12 ~ 15 % 다. 즉 긴장응력의 실질
상한이 약 1,378 MPa 로 끌어내려진다.

```python
from concreteproperties_kds.kds24 import stress_after_transfer

stress_after_transfer(fpy=1600)                            # 1200.0 (원문, 기본값)
stress_after_transfer(fpy=1600, fpu=1860, reading="EN")    # 1360.0
```

`design_girder` 는 `transfer_reading` 인자로 어느 쪽을 검토할지 고른다.
**기본값은 `"EN"` 이며, 이는 해석상의 선택이다.** 실무에서는 발주자·감리와
맞추어야 한다.

```python
from concreteproperties_kds.kds24 import EXAMPLE_SECTIONS, design_girder

kwargs = dict(section=EXAMPLE_SECTIONS["PSC-I 2.0m"], span=30.0, a_p=3467.5)

design_girder(**kwargs).adequate                              # True
design_girder(**kwargs, transfer_reading="원문").adequate      # False
```

## 손실

기준은 손실을 두 묶음으로 나눈다.

| 손실 | 조문 | 지간 30 m 예시 |
|---|---|---|
| 마찰 | 식 (1.5-11), 표 1.5-2 | 7.9 % |
| 정착장치 활동 | 1.5.7.4 | 2.8 % |
| 탄성변형 | 식 (1.5-10) | 2.1 % |
| **즉시 손실 계** | | **12.9 %** |
| 크리프 + 건조수축 + 릴랙세이션 | 식 (1.5-12), (3.3-1)~(3.3-3) | 8.1 % |
| **총 손실** | | **20.9 %** |

**가장 큰 손실은 마찰이다.** 그리고 설계자가 실제로 줄일 수 있는 유일한 큰
손실이기도 하다. 크리프·건조수축은 재료와 환경이 정하지만, 마찰은 곡률각을
줄이거나 양쪽에서 긴장하거나 윤활 덕트를 쓰면(표 1.5-2 에서 $\mu$ 가
0.19 → 0.12) 줄어든다.

지간이 길어지면 총손실도 는다(30 m 20.9 % → 50 m 25.5 %). 마찰이 길이에
비례하기 때문이다. **긴 거더는 넣은 힘을 더 많이 잃으면서 더 많은 힘을
필요로 한다.**

## PSC I형 거더

### 단면

`IGirder` 는 아래에서 위로 하부플랜지 → 경사부 → 복부 → 경사부 → 상부플랜지의
다섯 구간으로 단면을 나누고, 각 구간을 **정확히 적분**해 성질을 구한다.

```python
from concreteproperties_kds.kds24 import EXAMPLE_SECTIONS

props = EXAMPLE_SECTIONS["PSC-I 2.0m"].properties()
props.area, props.y_b, props.inertia    # 0.881 m², 962 mm, 0.4176 m⁴
```

:::{warning}
`EXAMPLE_SECTIONS` 는 **예시 단면이며 어떤 표준도도 아니다.** 형상은 일반적인
PSC I형 거더를 본떴을 뿐이므로, 실제 설계에는 해당 표준도나 제작사 제원을
써야 한다.
:::

하부플랜지가 상부보다 넓어 도심이 중앙보다 아래(약 $0.475H$)에 온다. PSC
거더에서 이 성질이 중요한 이유는 **편심** 때문이다. 도심이 낮아야 긴장재를
도심에서 멀리 둘 수 있다.

### 합성 단면과 시공 순서

PSC 거더교는 보통 거더를 먼저 놓고 바닥판을 나중에 친다. 그래서 하중마다
저항하는 단면이 다르다.

| 하중 | 저항 단면 | 지간 30 m 몫 |
|---|---|---|
| 거더 자중 | 거더 단독 | 35.3 % |
| 굳지 않은 바닥판 | 거더 단독 | 24.1 % |
| 2차 고정하중 | 합성 단면 | 4.9 % |
| 활하중 + 충격 | 합성 단면 | 35.7 % |

합성으로 하연 단면계수가 1.47 배가 되지만, **전체 하중의 59 % 는 그 혜택을 못
받는다.** 굳지 않은 바닥판은 하중이지 단면이 아니다.

### 텐던 배치와 핵거리

지간 중앙에서는 편심이 클수록 좋고, 상한은 응력이 아니라 하부플랜지의
**기하**다. 그런데 단부에서는 자중 모멘트가 0 이라 프리스트레스가 만드는 상연
인장을 상쇄할 것이 없고, 상한이 **핵거리**로 내려온다.

$$
e \le \frac{Z_t}{A} \quad (\text{단부, 영응력 기준})
$$

지간 30 m 예시에서 중앙 편심은 762 mm 인데 핵거리는 457 mm 다. 중앙 편심을
단부까지 그대로 끌고 가면 상연 인장이 3.30 MPa 로 긴장 시
$f_{ctk} = 2.20$ MPa 를 넘어 **거더 단부 상연이 갈라진다.**

**텐던을 휘는 것(드레이프)은 시공 편의가 아니라 응력이 요구하는 형상이다.**

### 무엇이 단면을 정하는가

지간별로 모든 한계상태를 만족하는 최소 강연선 수량을 구하면 이렇게 갈린다.

| 지간 | 단면 | 가닥 | 총손실 | $M_{Rd}/M_{Ed}$ | 지배 한계상태 |
|---|---|---|---|---|---|
| 20 m | PSC-I 1.4m | 16 | 20.5 % | 1.05 | 극한 휨강도 |
| 25 m | PSC-I 1.7m | 20 | 20.5 % | 1.01 | 극한 + 사용 |
| 30 m | PSC-I 2.0m | 25 | 20.9 % | 1.01 | 극한 + 사용 |
| 35 m | PSC-I 2.0m | 36 | 23.1 % | 1.09 | **사용 (균열)** |
| 40 m | PSC-I 2.3m | 42 | 23.3 % | 1.09 | **사용 (균열)** |
| 45 m | PSC-I 2.7m | 48 | 23.7 % | 1.11 | **사용 (균열)** |
| 50 m | PSC-I 2.7m | 61 | 25.5 % | 1.14 | **사용 (균열)** |

**35 m 를 넘으면 극한 휨강도가 1.09 ~ 1.14 배로 남는데도 강연선을 더 넣어야
한다.** 한계상태설계법이라고 해서 극한이 항상 지배하는 것이 아니다.

이유는 두 요구가 같은 속도로 자라지 않기 때문이다.

- 극한 휨강도가 요구하는 것은 긴장재의 인장력 $A_p f_{pd}$ 다. 강연선을 늘리면
  거의 비례해 는다.
- 사용한계상태가 요구하는 것은 하연 압축응력 $P/A + Pe/Z_b$ 이고, 이것을
  깎아내리는 것은 $M/Z_b$ 다. 지간이 길어지면 $M$ 은 $L^2$ 로 느는데 $Z_b$ 는
  형고가 허용하는 만큼만 큰다.

## KDS 14 와의 대조

같은 단면의 극한 휨강도를 두 방식으로 계산하면 **KDS 24 가 4.8 % 크게** 나온다.

| 기준 | 강재 응력 | 콘크리트 | $a$ | 강도 |
|---|---|---|---|---|
| KDS 24 | $\phi_s f_{py}$ = 1,440 | $\phi_c \alpha_{cc} f_{ck}$ = 14.92 | 138 mm | $M_{Rd}$ = 10,091 |
| KDS 14 | $f_{py}$ = 1,600 | $0.85 f_{ck}$ = 22.95 | 97 mm | $M_n$ = 11,327 |
| | | | $\times \phi = 0.85$ | $\phi M_n$ = 9,628 |

휨은 **강재의 인장력이 지배**하므로 KDS 24 의 $\phi_s = 0.90$ 이 KDS 14 의 단면
$\phi = 0.85$ 보다 덜 깎는다. 콘크리트에 걸린 0.65 는 압축블록을 깊게 할
뿐(97 → 138 mm) 팔길이를 조금 줄이는 데 그친다.

[철근콘크리트 보에서 본 $+3.9\,\%$](comparison.md) 와 같은 방향, 비슷한 크기다.

:::{note}
위 비교는 두 기준의 **안전율 배치**만 견주려고 강재 응력을 양쪽 모두 $f_{py}$ 로
두었다. 실제 KDS 14 설계에서는 부착 긴장재의 극한 응력 $f_{ps}$ 를 따로
산정하므로 값이 달라진다.
:::
